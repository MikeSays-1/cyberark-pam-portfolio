# CyberArk Privileged Access Management Portfolio

This portfolio documents my CyberArk Privileged Access Management work within **Northwind Medical Systems**, a simulated enterprise environment designed to model privileged-account security and administrative access.

The environment includes CyberArk Digital Vault, PVWA, CPM, PSM, Active Directory, and Windows target systems.

The projects focus on privileged account onboarding, credential management, access control, password rotation, reconciliation, session brokering, monitoring, auditing, and privileged-account lifecycle management.

## Portfolio Projects

### Part 1 — Privileged Account Onboarding & Credential Management
Covers privileged account onboarding, account management, credential verification, password rotation, and CyberArk CPM operations.

**Project:** [Part 1. CyberArk PAM – Privileged Account Onboarding & Credential Management](https://github.com/MikeSays-1/CyberArk-PAM-Account-Onboarding)

### Part 2 — Privileged Access Control & Session Auditing
Covers Safe permissions, privileged access controls, PSM-brokered sessions, credential isolation, session recording, monitoring, and auditing.

**Project:** [Part 2. CyberArk PAM – Privileged Access Control & Session Auditing](https://github.com/MikeSays-1/cyberark-privileged-access-session-audit)

### Part 3 — Privileged Account Recovery & Lifecycle Management
Covers credential mismatch recovery, password reconciliation, privileged-account disablement, privilege removal, and account deprovisioning.

**Project:** [Part 3. CyberArk PAM – Privileged Account Recovery & Lifecycle Management](https://github.com/MikeSays-1/cyberark-recovery-and-lifecycle)
